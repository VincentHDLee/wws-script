# Pacific Front 自动排阵与游玩

当前版本：**v1.9.2**。支持亚服、欧服、美服和国服。

将 [pacific-front-auto.user.js](./pacific-front-auto.user.js) 全文替换到油猴中的旧脚本并保存，刷新游戏页面，确认面板版本为 v1.9.2。完整安装、配置及使用方法见 [使用说明](./使用说明.md)。

## v1.9.2 更新说明

- 常规排阵后仍有对战槽位低于 80%，才进入无限制组合搜索；不会仅因为未达 100% 就无限搜索。
- 高难关进入无限制搜索前先填入当前最佳卡牌及增益品草稿，搜索中找到更好的配置时更新页面，期间不提交战斗。停止后保留最近填入的草稿。
- 搜索联合考虑卡牌排列与每槽两组增益品，支持四槽共八件物品；由原版引擎计算己方、敌方、相邻及方向效果，遵守库存和关卡限制。
- 每格 100% 仍是优化目标；任何对战槽位低于 90% 均不自动提交，开战前重新读取状态并复核。
- 保留有效补给购买、优先减少不必要的增益品，以及全部行动结算后返回主菜单的规则。

已通过原版引擎和模拟流程回归测试，包括四槽各两件增益品联动、搜索中填入草稿、停止保留草稿及 80%/90% 门槛；尚未在四服分别完成真实账号端到端实测。

## 搜索长时间无结果或看似卡住

当选不出最佳方案、感觉搜索卡住时，可以重启脚本，重新读取局势并计算组合：

1. 点击“停止”，等待日志确认“已停止”。
2. 再点击“自动游玩”或“自动选卡”，重新排阵。
3. 如果页面无响应，或希望清除本页预测缓存，刷新游戏页面，待加载完成后再启动。

重启仍遵守每格 90% 才开战的规则。相同卡牌、库存和战斗条件下可能再次得到相同组合；重启不保证一定找到更优解。已经发出的购买或战斗请求可能仍会完成，重新运行前请核对页面状态。
